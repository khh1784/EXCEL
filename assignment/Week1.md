# 1️⃣ 학습 내용 정리

## 01-3. 엑셀의 기본 동작 원리 이해하기
> **셀 참조 방식에 대해 정리해주세요.**
* **`$` 기호의 역할**: 행이나 열의 위치를 고정할 때 사용하며, 수식 입력 중 `F4` 키를 누르면 참조 방식이 순차적으로 변경됨.
* **상대 참조 (예: `A1`)**: `$` 기호가 없는 기본 형태로, 수식을 복사하거나 자동 채우기를 실행하면 참조하는 셀의 위치가 상대적으로 함께 이동하며 변함.
* **절대 참조 (예: `$A$1`)**: 행과 열 앞에 모두 `$` 기호가 붙어 위치가 완전히 고정된 형태. 수식을 어디로 복사하든 항상 지정된 단 하나의 셀만 참조=.
* **혼합 참조 (예: `A$1` 또는 `$A1`)**: 행이나 열 중 한 방향만 고정하는 참조 방식.
  * `A$1` (행 고정): 아래로 자동 채우기를 해도 행 번호는 고정되지만, 오른쪽으로 채우면 열 문자(A, B, C...)는 바뀜.
  * `$A1` (열 고정): 오른쪽으로 자동 채우기를 해도 열은 고정되지만, 아래로 채우면 행 번호(1, 2, 3...)는 바뀜.

## 01-5. 실무자면 꼭 알아야 할, 필수 단축키 모음
> **이번에 배운 단축키에 대해 정리해주세요.**
* **셀 및 서식 관리**:
  * `Ctrl + 1`: 셀 서식 대화상자 표시
  * `F2`: 선택한 셀을 즉시 편집 모드로 전환
  * `Ctrl + Enter`: 선택한 전체 범위에 동일한 데이터나 수식을 한 번에 일괄 입력
* **기본 제어 및 편집**:
  * `F4`: 셀 참조 방식 변경(상대/절대/혼합) 또는 직전에 실행한 서식/작업 반복 실행
  * `Ctrl + Z` / `Ctrl + Y`: 작업 실행 취소 / 다시 실행
  * `Shift + F10`: 마우스 오른쪽 버튼 클릭 팝업 메뉴 표시
* **범위 이동 및 선택**:
  * `Ctrl + 방향키`: 데이터가 연속으로 입력된 영역의 맨 끝 셀로 즉시 이동
  * `Ctrl + Shift + 방향키`: 현재 셀부터 데이터 맨 끝까지의 범위를 한 번에 일괄 선택
  * `Ctrl + PageUp / PageDown`: 이전 / 다음 시트로 즉시 이동
  * `Ctrl + A`: 현재 워크시트 전체 범위 선택
* **파일 및 시트 관리**:
  * `Ctrl + S`: 파일 저장
  * `F12`: 다른 이름으로 저장 대화상자 표시
  * `Shift + F11`: 현재 시트의 왼쪽에 새로운 시트 삽입
  * `Ctrl + N`: 새 통합 문서 만들기
* **고급 서식 및 구조 조절**:
  * `Ctrl + Shift + L`: 자동 필터 일괄 적용 / 해제
  * `Alt + Shift + ➔ / ⬅`: 행 또는 열 그룹 설정 및 그룹 해제
  * `Ctrl + 9` / `Ctrl + 0`: 선택된 행 숨기기 / 열 숨기기
  * `Alt + Enter`: 한 셀 안에서 강제로 줄 바꾸기


## 02-1. 보기 좋은 표, 활용할 수 있는 데이터를 위한 필수 상식
> **데이터와 표를 비교해주세요**
* **표(Table/서식)**: 사람이 화면으로 보거나 종이로 인쇄해서 보기 편리하게 시각화된 디자인 서식. 가독성을 위해 셀 병합이 많이 쓰이지만, 이로 인해 데이터 정렬, 필터, 수식 사용 및 피벗 테이블 연산 시 심각한 오류가 발생할 수 있음.
* **데이터(Raw Data)**: 컴퓨터(시스템)와 데이터 분석 도구가 즉시 인식하고 가공할 수 있는 정형화된 형태의 원본 데이터 집합. 셀 병합이 절대 없어야 하며, 첫 번째 행에는 오직 '한 줄의 머리글(필드명)'만 존재해야 하고, 가로(열)는 고유 항목, 세로(행)는 누적된 값 형식으로 채워짐.

> **셀 병합 기능을 자제해야 하는 이유를 정리해주세요.**
1. **정렬 및 필터링 불가**: 병합된 셀이 포함되어 있으면 데이터의 순서를 올바르게 정렬하거나 특정 조건으로 필터링할 수 없음.
2. **수식 및 자동 채우기 오류**: 엑셀은 셀 병합 시 왼쪽 위 첫 번째 셀에만 값을 저장하고 나머지 셀은 빈 셀로 인식. 따라서 수식을 작성하고 자동 채우기를 수행할 때 참조 오류나 빈 값이 계산되는 문제가 생김.
3. **피벗 테이블 분석 불가**: 원본 데이터에 셀 병합이 있으면 정상적으로 요약되거나 분석되지 않아 피벗 테이블 기능을 원천적으로 사용할 수 없음.
4. **범위 선택 제한**: 특정 행이나 열만 선택하려 할 때 병합된 셀 영역까지 한꺼번에 드래그 범위가 넓어져 편집 및 수정 작업에 심각한 방해를 받음.
